# cakesmash-ig-assets

Public image host for Cakesmash Media Instagram publishing.

Instagram's Content Publishing API fetches media by public URL ("We cURL media used in
publishing attempts, so the media must be hosted on a publicly accessible server"). There is
no file-upload path, so these six JPEGs are hosted here to be fetched at publish time.

These are the same images published to @cakesmash_media. Nothing private lives in this repo.
